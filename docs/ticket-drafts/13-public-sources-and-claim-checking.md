# 13: Check a claim against public sources

**What to build:** A Learner investigates a question with the Tutor, sees the public sources actually found, compares a claim with evidence, and can revise their conclusion or the Tutor's answer.

**Blocked by:** 03 — Connect model access with visible usage controls.

**Status:** draft — awaiting breakdown approval and tracker configuration.

**Source stories:** 37, 38, 39, 40, 41, 56, 59.

- [ ] A session can request public-source research and display the source references actually returned by the research capability.
- [ ] The Learner can connect a claim to its supporting material and discuss conflicting or insufficient evidence.
- [ ] Failed lookup or missing support is represented honestly; the app does not fabricate a source or treat a citation-shaped string as verified retrieval.
- [ ] The external capability set permits finding and reading public information only. Requests to create accounts, make purchases, send messages, or use general computer control cannot execute.
- [ ] Source content cannot override operating instructions, expose another Learner's information, or expand tool permissions.
- [ ] Chargeable research uses shared allowance enforcement; exhaustion or failure leaves the learning session and saved work accessible.
- [ ] Browser scenarios use controlled source fixtures for a supported claim, a contradiction, a missing source, a failed lookup, and an attempted capability expansion.

**Demo:** Investigate a fictional claim, inspect two disagreeing sources, and revise an explanation while demonstrating that an unrelated external action cannot execute.

**Scope:** This slice adds research to the existing coaching session. It does not require a game, image upload, or Portfolio to be complete.
